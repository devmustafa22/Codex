# مراجع التصميم وتجربة الاستخدام

تاريخ مراجعة المصادر: **2026-10-06**.

التصميم يستلهم الصورة المرجعية: درجات أخضر هادئة، بطاقات بإحصاءات مختصرة، شريط تنقل ثابت، ورسوم واضحة. جرى تحويل الفكرة إلى مساحة شخصية لتنظيم المهام، نمو المهارات، التقويم واليوميات.

## ما الذي تحققنا منه؟

حجبت شبكة بيئة التطوير صفحات المنتجات المباشرة بخطأ `403 Forbidden`. أمكن قراءة الملفات الرسمية المنشورة على GitHub و`raw.githubusercontent.com`؛ لذلك النتائج التالية مستندة إلى تلك المصادر، وليست ادعاءً بمراجعة جميع واجهات المنتجات بصريًا.

| المرجع  | ما يؤكده المصدر الرسمي                                                   | الفكرة المناسبة للمشروع                                |
| ------- | ------------------------------------------------------------------------ | ------------------------------------------------------ |
| Linear  | تنظيم المشكلات والمشاريع وخطط العمل، مع دورات وحالات سير عمل في مخطط API | تقسيم المهام إلى حالات واضحة، وربطها بهدف أو مهارة     |
| Todoist | أولويات، وسوم، مهام فرعية، تواريخ استحقاق، مدد وتكرار ضمن نموذج المهمة   | قائمة اليوم، فلاتر عملية، معلومات مختصرة لكل مهمة      |
| Notion  | عروض قائمة وجدول ولوحة وتقويم وخط زمني، مع فلترة وترتيب                  | عرض نفس السجل بأكثر من طريقة بدون تكرار إدخال البيانات |
| GitHub  | تقويم مساهمات سنوي؛ الضغط على مربع اليوم يعرض نشاط ذلك اليوم             | خريطة نشاط سنوية مرتبطة بسجل التعلم واليوميات          |

المصادر التي تمت قراءتها:

- [Linear: التعريف الرسمي](https://github.com/linear/linear/blob/master/README.md) و[مخطط البيانات](https://github.com/linear/linear/blob/master/packages/sdk/src/_generated_documents.graphql).
- [Todoist: نماذج البيانات الرسمية](https://github.com/Doist/todoist-api-python/blob/main/todoist_api_python/models.py).
- [Notion: أنواع عروض البيانات الرسمية](https://github.com/makenotion/notion-sdk-js/blob/main/src/api-endpoints/views.ts).
- [GitHub: مصدر وثيقة تقويم النشاط](https://github.com/github/docs/blob/main/content/account-and-profile/how-tos/contribution-settings/viewing-contributions-on-your-profile.md). [رابط الوثيقة المنشورة](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/viewing-contributions-on-your-profile).

## القرارات المقترحة

1. **نظرة عامة:** مهام اليوم، ملخص النمو، النشاط الأسبوعي والوصول السريع للإضافة.
2. **المهام:** قائمة ولوحة حالات، بحث، أولوية وربط المهمة بمهارة.
3. **المهارات:** وقت التعلم، أهداف قابلة للقياس وسجل جلسات؛ النسبة تكون مرتبطة بهدف محدد.
4. **التقويم:** التنقل بين الأيام والأشهر وعرض السنة، مع فتح تفاصيل اليوم.
5. **اليوميات:** تسجيل الإنجاز، ما تعلمته والملاحظات؛ منها تتولد خريطة النشاط.
6. **التحليلات والإعدادات:** مراجعة التقدم، تخصيص الواجهة وتصدير/استيراد نسخة احتياطية.

هذه مقترحات تصميم؛ وجودها في المرجع لا يعني أن كل ميزة منه أُضيفت إلى هذه النسخة. معيار الاستخدام هو أن يتحول التسجيل اليومي القصير إلى تقدم واضح، مع تقليل تكرار المعلومات بين الشاشات.

التخزين الشخصي في المتصفح هو اختيار هذه النسخة. المزامنة بين الأجهزة عبر خدمة مثل Supabase تطوير مستقل يمكن إضافته لاحقًا.
